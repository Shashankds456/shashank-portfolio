## Featured Projects

### 1. AI-Based Unified Log Analyzer

An AI-powered enterprise log analysis application developed to analyze and diagnose different types of system and application logs.

**Key Features:**
- Supports `.log` files, Event Viewer logs, ETL traces and crash dump analysis.
- Identifies and groups recurring error patterns.
- Uses rule-based analysis and AI-based classification.
- Uses RAG and knowledge-base techniques for unknown error patterns.
- Provides root cause, severity and recommended fixes.
- Includes error correlation and timeline-based analysis.
- Built with Flask, Python, Ollama and SQLite.

**Technologies:** Python, Flask, SQLite, Ollama, RAG, LLMs
